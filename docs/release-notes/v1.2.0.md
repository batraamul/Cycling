## Cycling v1.2.0 — activity modes, Google Drive backup, Army & Air Force themes

**Update:** install `Cycling-v1.2.0.apk` over v1.1.0 (or v1.0.0). Your steps, rides and calibrations are kept
(same signing key; the database upgrades automatically to schema 3 and existing rides become *Cycling* sessions).

### New
- **Activity modes** on the Today screen: 🚴 Cycling, 🏃 Running, 👟 Jogging (GPS + steps, pace, cadence),
  🔁 Treadmill (steps × step length, works indoors without GPS) and 💪 Exercise (timer + calorie estimate).
  Daily walking pauses during every activity, so nothing is counted twice. Running/treadmill steps count towards
  your daily step total once.
- **Google Drive backup** (Settings › Backup & restore): a JSON file in your Drive, refreshed daily and after each
  activity. **Restore** after a phone reset from the first onboarding screen or Settings. Restore merges and never
  deletes; restoring twice changes nothing; a damaged file changes nothing. The app still has no internet permission.
- **Two new themes:** *Army* (olive, khaki, camouflage) and *Air Force* (blue sky, three jets with tricolour smoke).
  Tribute designs only — no official crests or insignia.
- **Better visibility:** subtle background texture per theme, raised high-contrast buttons (≥ 56 dp), bordered
  cards, bolder labels and accent-barred stat tiles.
- The "Rides" tab is now **Activities**.

### Changed
- Database schema v3 (activity type and steps per session), with tested migrations from v1 and v2.
- The cycling GPS calibration factor is applied to cycling only.
- Fix found while testing: during a session the step-counter baseline is now saved only together with the
  session's step total (previously a walking flush could save it separately).

### Verification status
- 74 automated tests pass (unit, integration, migration, backup/restore); Android Lint passes; mutation checks
  confirmed the key tests fail when the protected logic is broken.
- All 10 themes rendered and reviewed as screenshots (Robolectric native graphics).
- **Not yet tested on a physical phone**, including Google Drive writing — see docs/TESTING.md "v1.2.0 extra checks".

### Known limitations
- Treadmill distance is only as good as your step length (calibrate a running step length).
- If Google Drive revokes write access, Settings shows "Last backup failed" — choose the file again.
